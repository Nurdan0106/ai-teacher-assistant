# Сократ — AI-тьютор по информатике

AI-репетитор для школ Казахстана (5–11 класс) на **казахском языке**.
Метод Сократа: задаёт наводящие вопросы вместо готовых ответов.
Программа ГОСО РК — темы по информатике для каждого класса.

---

## Жылдам бастау (Быстрый старт)

### 1. Требования

- **Node.js 18+** — [nodejs.org](https://nodejs.org)
- **Ключ Anthropic API** — [console.anthropic.com](https://console.anthropic.com)

### 2. Установка

```bash
cd backend
npm install
cp .env.example .env
```

Открой `.env` и вставь свой ключ:

```
ANTHROPIC_API_KEY=sk-ant-...
PORT=3000
```

### 3. Запуск

```bash
node server.js
```

Сервер: `http://localhost:3000`
Проверка: `http://localhost:3000/health` → `{"status":"ok"}`

### 4. Открой приложение

Двойной клик на `frontend/index.html` — или открой через браузер напрямую.
Кабинет учителя: `frontend/teacher.html`

> Live Server (VS Code): статистика обновляется корректно — `stats.json` пишется
> уже после отправки ответа, так что перезагрузки страницы во время чата нет.

## Для учителей

Открой `frontend/teacher.html` или нажми **"Мұғалім кабинеті"** в шапке сайта.

### Вкладка 1 — Сабақ жоспары (План урока)

1. Выбери класс и тему
2. Введи имя учителя
3. Нажми **"Жоспар жасау"** → генерация занимает 30–60 сек
4. Скачай кнопкой **"⬇ Жоспарды жүктеу"** (текстовый файл)

Формат по МЖМБС РҚ — 7 обязательных разделов:
*Жалпы мәліметтер → Мақсаттар → Құралдар → Сабақтың барысы (6 кезең) → Үй тапсырмасы → Бағалау критерийлері*

Для печати: `Ctrl+P` — навигация и кнопки скрыты, виден только план.

### Вкладка 2 — ҰБТ тесттері (Тесты в стиле ЕНТ)

1. Выбери класс, тему, количество вопросов (5–20)
2. Нажми **"Тест жасау"**
3. Каждый вопрос: 4 варианта ответа (A/B/C/D)
4. Кнопка **"Жауапты көрсету"** открывает ответ с объяснением
5. **"⬇ Тестті жүктеу"** — сохранить в .txt

### Вкладка 3 — Статистика

- Общее кол-во диалогов, среднее количество сообщений
- Самые популярные темы и классы
- Автообновление каждые 60 сек

## Педагогический принцип (метод Сократа)

AI **никогда** не даёт готовых ответов и не пишет код за ученика:

| Запрос ученика | Ответ Сократа |
|----------------|---------------|
| "Напиши мне код" | "Что именно должен делать первый шаг алгоритма?" |
| "Переведи 42 в двоичную" | "Как ты найдёшь остаток от деления на 2?" |
| Ошибка в рассуждении | "Что произойдёт, если выполнить этот шаг с числом 0?" |

Адаптация по классу (prompts.js):
| Класс | Стиль объяснений |
|-------|-----------------|
| 5 | Мультфильмы, игры, бытовые примеры |
| 6–7 | Схемы, пошаговые алгоритмы |
| 8–9 | Псевдокод, ҰБТ-формат |
| 10–11 | Олимпиадный уровень, сложность алгоритмов |

## API-эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| `GET`  | `/health`                | Статус сервера |
| `GET`  | `/api/curriculum/:grade` | Темы для класса (5–11) |
| `POST` | `/api/chat`              | Чат с тьютором (SSE-стриминг) |
| `POST` | `/api/lesson-plan`       | Сгенерировать план урока |
| `POST` | `/api/test`              | Тест в стиле ҰБТ (JSON) |
| `GET`  | `/api/glossary/:grade`   | IT-глоссарий на казахском |
| `GET`  | `/api/stats`             | Статистика сессий |

**Пример — тест для 8 класса:**
```bash
curl -X POST http://localhost:3000/api/test \
  -H "Content-Type: application/json" \
  -d '{"grade": 8, "topic": "Циклдер", "count": 5}'
```

## Технический стек

| Компонент | Технология |
|-----------|-----------|
| AI-модель | `claude-sonnet-4-6` (Anthropic) |
| Backend | Node.js 18 + Express 4 |
| AI-стриминг | Server-Sent Events (SSE) |
| Frontend | Vanilla HTML / CSS / JS |
| Шрифты | Fraunces · Manrope · JetBrains Mono |
| Деплой | Railway (backend) + Netlify (frontend) |

**Оптимизации:**
- `cache_control: ephemeral` — системный промпт кэшируется между запросами одного класса/темы
- `maxRetries: 1` + `timeout: 30s` для чата, `timeout: 90s` для планов и тестов
- SSE-стриминг — первые токены появляются через ~1 сек
- Лимит 20 запросов/мин на IP (rate limit)
